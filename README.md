# makefun-tired-dark-lord

A 100-word villain monologue for make.fun's "The Tired Dark Lord" bounty.

Varek the Black has held the siege of Alder Ford far too long. He had a speech ready for the hero. It is in his coat. His other coat. The program writes his monologue to the output file after checking it lands on 100 words and fits the 600-character gate, nothing fancier than that.

## Run it

```sh
node --experimental-strip-types main.ts
```
